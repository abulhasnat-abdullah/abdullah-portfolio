# Watercolour Art (Instagram · @aquarelle_verse)

Drop your artwork image files into **this folder**.

- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`
- Every image you add here appears automatically in the "Watercolour Art"
  masonry gallery in the Art & Design section — no code changes needed.
- The file name becomes the caption (dashes/underscores become spaces),
  e.g. `sunset-study.jpg` → "sunset study".
- Images are sorted by file name, so prefix with numbers to control order,
  e.g. `01-first.jpg`, `02-second.jpg`.
