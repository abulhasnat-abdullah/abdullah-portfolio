# Abul Hasnat Abdullah — Portfolio

Modern portfolio site for a robotics and automation engineer. Built with React, Vite, and SCSS.

## Layout

Tab-based portfolio inspired by section navigation patterns:

- **Desktop:** sticky sidebar with profile photo + section tabs
- **Mobile:** bottom category tabs (Home, History, Showcase, More) + section pills
- **URL hash routing:** each section has a deep link (`#about`, `#projects`, `#certificates`, etc.)

## Sections

- About (with profile photo)
- Experience & Highlights
- Projects
- Skills
- Research
- Certifications & Courses
- Contact

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

Deploy the `dist/` folder to GitHub Pages, Vercel, or Netlify.
